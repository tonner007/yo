🚀 Návod - Nasazení YO App na tonner.my.id

✅ Testováno a funkční

TONNER.MY.ID POVOLEN Vite server nyní přijímá požadavky z tonner.my.id

curl -H "Host: tonner.my.id" http://localhost:3000 → HTTP 200 OK
curl -H "Host: localhost" http://localhost:3000 → HTTP 200 OK
✅

Krok 1: Povolit hosta

Přidáno tonner.my.id do server.allowedHosts v vite.config.js

allowedHosts: [ 'tonner.my.id', 'localhost', '127.0.0.1', '0.0.0.0' ]
✅

Krok 2: Změnit port

Port změněn z 5173 na 3000 pro kompatibilitu s předchozími aplikacemi.

server: { port: 3000, host: true, open: false }
🔧

Krok 3: Nginx Reverse Proxy

Na serveru tonner.my.id nastavit Nginx, který bude přesměrovávat traffic na port 3000.

# /etc/nginx/sites-available/tonner.my.id server { listen 80; server_name tonner.my.id; location / { proxy_pass http://localhost:3000; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; } }
🔒

Krok 4: SSL Certifikát

Přidat HTTPS pomocí Let's Encrypt certifikátu.

sudo apt install certbot python3-certbot-nginx sudo certbot --nginx -d tonner.my.id

🔧 Kompletní Nginx konfigurace pro tonner.my.id

# 1. HTTP → HTTPS redirect server { listen 80; listen [::]:80; server_name tonner.my.id www.tonner.my.id; # Redirect to HTTPS return 301 https://tonner.my.id$request_uri; } # 2. HTTPS server server { listen 443 ssl http2; listen [::]:443 ssl http2; server_name tonner.my.id www.tonner.my.id; # SSL certificates (after certbot) ssl_certificate /etc/letsencrypt/live/tonner.my.id/fullchain.pem; ssl_certificate_key /etc/letsencrypt/live/tonner.my.id/privkey.pem; # SSL optimization ssl_protocols TLSv1.2 TLSv1.3; ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512; ssl_prefer_server_ciphers off; # Root location location / { proxy_pass http://localhost:3000; # Headers for Vite proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection 'upgrade'; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; # Timeouts proxy_connect_timeout 60s; proxy_send_timeout 60s; proxy_read_timeout 60s; } # Static files cache location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ { expires 1y; add_header Cache-Control "public, immutable"; } }

🚀 Rychlý deploy script pro tonner.my.id

#!/bin/bash # deploy-yo-app.sh echo "🚀 Nasazování YO App na tonner.my.id" # 1. Aktualizovat systém sudo apt update && sudo apt upgrade -y # 2. Nainstalovat Nginx sudo apt install nginx -y # 3. Vytvořit Nginx konfiguraci sudo tee /etc/nginx/sites-available/tonner.my.id > /dev/null << 'EOF' server { listen 80; server_name tonner.my.id; location / { proxy_pass http://localhost:3000; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; } } EOF # 4. Povolit konfiguraci sudo ln -sf /etc/nginx/sites-available/tonner.my.id /etc/nginx/sites-enabled/ sudo rm -f /etc/nginx/sites-enabled/default # 5. Testovat a restartovat Nginx sudo nginx -t && sudo systemctl restart nginx # 6. Instalace Node.js (pokud není) curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash - sudo apt install nodejs -y # 7. Spustit aplikaci (předpokládá se, že kód je v /home/user/yo-app) cd /home/user/yo-app npm install npm run dev & echo "✅ Nasazení dokončeno! Aplikace běží na http://tonner.my.id"
