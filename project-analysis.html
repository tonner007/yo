🎯 Akční plán - Odstranění Base44 závislostí

1
Odstranit Base44 SDK závislosti
Odstranit @base44/sdk a @base44/vite-plugin z package.json
2
Nahradit base44Client.js
Vytvořit vlastní API klient místo Base44 DB objektu. Nahradit globalThis.__B44_DB__ mock objektem.
3
Refaktorovat AuthContext.jsx
Odstranit Base44 autentizaci a vytvořit vlastní auth systém nebo použít ConnectKit/Wagmi.
4
Aktualizovat app-params.js
Odstranit Base44 specifické parametry (VITE_BASE44_*) a nahradit vlastní konfigurací.
5
Upravit vite.config.js
Odstranit Base44 Vite plugin a upravit konfiguraci pro standalone běh.
6
Vyčistit index.html a README.md
Odstranit Base44 specifický kód a dokumentaci z HTML a README souborů.
7
Přidat wallet integration
Integrovat ConnectKit/Wagmi pro wallet connection místo Base44 auth.
